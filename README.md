# Beam Designer

Beam Designer is a Python Tkinter desktop app for analyzing simply supported or cantilever beams. It accepts span, section, point-load, and uniform-load inputs; calculates reactions, shear, moment, deflection, and bending stress; and shows pass/fail checks with embedded matplotlib diagrams. Designs can be saved and reopened, results exported to CSV, and a calculation sheet exported to PDF.

## Install

```bash
python3 -m pip install -r requirements.txt
```

## Start

```bash
python app.py
```
